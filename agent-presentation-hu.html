A simple_agent.py és a corporate_offsite_planner_agent.py alapján

Hogyan működik egy agent?

Egy modell, egy prompt, és egy folyamat, amely eszközökkel, memóriával és új érzékekkel bővíthető.

Az alapmodell

Ez továbbra is Python.

Az „agent” nem varázslat: egy Python-objektum, amely üzeneteket kap, modellt hív, majd üzeneteket ad vissza.

Prompt küldése

Az üzenet bemegy, a válasz kijön.

05 / 17
Mi történik belül?

A kérés üzenetfolyammá válik.

Egy egyszerű kérdésnél rövid a folyamat. Eszközök esetén az agent további lépéseket is tehet a válasz előtt.

A / BEMENET

HumanMessage

A természetes nyelvű kérés strukturált adattá válik.

B / DÖNTÉS

Modellhívás

A modell elolvassa az utasítást és a beszélgetést.

C / MŰVELET

Opcionális eszköz

Ha van eszköz, a modell kérheti annak futtatását.

D / KIMENET

AIMessage

A segédfüggvény kiveszi vagy kiírja a választ.

Lényeg: a modell döntést és szöveget generál, a Python és az eszközök végzik a külső munkát.

06 / 17
4. lépés / streaming

Ne várjuk meg az egész választ.

Az agent.stream() üzenetrészleteket ad vissza. A segédfüggvény azonnal kiírja a nem üres darabokat.

Ugyanaz a modell és ugyanaz a prompttípus, csak gyorsabbnak érződik a válasz. 

for token, metadata in agent.stream(
    {"messages": user_prompt},
    stream_mode="messages"
):
    if token.content:
        print(token.content,
              end="", flush=True)

7. lépés / koordinátor-állapot

Rögzítsük a tényeket delegálás előtt.

Az update_state a helyszínt, a létszámot és a célt az OffsiteState-be írja. Így minden specialista ugyanazokat a tényeket használhatja.

Az állapot megosztott adat. A prompt maga a kérés.

class OffsiteState(AgentState):
    destination: str
    attendee_count: str
    objective: str

@tool
def update_state(
    destination, attendee_count,
    objective, runtime
):
    return Command(update={
        "destination": destination,
        "attendee_count": attendee_count,
        "objective": objective,
    })

A teljes kép

Prompt be. Összehangolt javaslat ki.

Kezdjünk egyszerű prompttal. Ezután csak azt a képességet adjuk hozzá, amelyre a feladatnak szüksége van: eszközt, állapotot, másik agentet vagy másik modellt.

Modell

Nyelvet generál, és eldönti, mi legyen a következő lépés.

Agent

Összeköti a modellt az üzenetekkel, eszközökkel és állapottal.

Eszközök

A modellen kívüli munkát végzik, például keresést.

Orkesztráció

Lehetővé teszi a specialista-válaszok összeállítását.

Kódműhely / eszközök

Egy eszköz meghívhat egy másik agentet.

A koordinátor eszköze egyszerű Python: állapotot olvas, üzenetet épít, meghívja a specialistát, majd visszaadja a végső üzenetet.

delegálás 
@tool
def plan_agenda(runtime):
    objective = runtime.state.get(
        "objective", "csapat-összhang"
    )
    people = runtime.state.get(
        "attendee_count", "a csapat"
    )
specialista hívása 
    query = f"Írj napirendet
    {people} főnek, ezzel a céllal:
    {objective}."

    response = agenda_agent.invoke(
        {"messages": [HumanMessage(
            content=query

    )
    return response["messages"][-1].content

        "tags": ["OFFSITE"],

print(response["messages"][-1].content)
