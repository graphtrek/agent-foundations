05 / 09
What happens inside

A request becomes a message loop.

For a basic question, the loop is short. With capabilities, the agent may take more steps before it answers.

A / INPUT

HumanMessage

Your plain-English request is packaged as structured data.

B / DECIDE

Model call

The model reads the system instruction and conversation.

C / ACT

Optional tool

If a tool exists, the model can request it.

D / OUTPUT

AIMessage

The helper extracts or prints the final response.

Key idea: the model generates decisions; Python and tools perform the outside-world work.

06 / 09
Step 4 / streaming

Do not wait for the whole answer.

agent.stream() yields message chunks. The helper prints each non-empty chunk as it arrives.

Same model. Same kind of prompt. Different delivery experience. 

agent = create_agent(
    model=model,
    system_prompt="You are a Python
    LangChain expert."
)

for chunk in agent.stream(
    {"messages": user_prompt},
    stream_mode="messages"
):
    print(chunk, end="")

Step 7 / coordinator state

Record facts before delegating.

update_state writes the destination, attendee count, and objective into OffsiteState. Every specialist can then use the same facts.

The state is shared data. The prompt is the request.

class OffsiteState(AgentState):
    destination: str
    attendee_count: str
    objective: str

@tool
def update_state(destination, attendee_count, objective, runtime):
    return Command(update={
        "destination": destination,
        "attendee_count": attendee_count,
        "objective": objective,
    })

The complete picture

Prompt in. Coordinated proposal out.

Start with a simple prompt. Add the smallest capability that the task needs: a tool, state, another agent, or a different model.

Model

Generates language and decides what to do next.

Agent

Connects the model to messages, tools, and state.

Tools

Perform work outside the model, such as search.

Orchestration

Lets a coordinator combine specialized answers.

Code lab / tools

A tool can call another agent.

The coordinator's tool is ordinary Python: read state, build a message, invoke the specialist, and return its final message.

delegate 
@tool
def plan_agenda(runtime):
    objective = runtime.state.get(
        "objective", "team alignment"
    )
    people = runtime.state.get(
        "attendee_count", "the team"
    )
specialist call 
    query = f"Draft a one-day
    agenda for {people} with
    objective: {objective}."

    response = agenda_agent.invoke(
        {"messages": [HumanMessage(
            content=query
        )]}
    )
    return response["messages"][-1].content

One prompt starts the whole plan.
